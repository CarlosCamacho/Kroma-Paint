
# Kroma Paint Manual

## Creating a project
Use File > New Project to create a new indexed image. The app starts at 200% zoom and centers the canvas.

## Painting modes
In the Patterns section, choose either Use Foreground or Use Pattern.
- Use Foreground paints with the active foreground slot only.
- Use Pattern paints using the selected pattern with the active FG/BG slots.

## Colors
Use Manage Colors to:
- pick active slots
- spread colors across a slot range
- load and save palettes
- choose a preset palette
- adjust slot colors with RGB, HSV, and HEX controls

## Patterns
Use Manage Patterns to:
- reorder patterns
- edit an 8x8 pattern
- preview the selected pattern
- load and save the full 16-pattern set
- switch between built-in pattern sets

## Layers
The newest layer is added at the top of the list.
You can:
- toggle visibility with the eye button
- rename a layer
- merge down
- flatten all layers

## Grid
Use Grid > Toggle Grid and Grid > Snap to Grid.
Grid is visible from 200% zoom and above.
Grid size supports separate horizontal and vertical values.

## Filters
Use Filters for indexed-friendly effects such as:
- Ordered Dither
- Edge Outline
- Checker Shade
- Invert Colors
- Low-pass
- High-pass
- Brightness / Contrast

## Exporting
Use File > Export Image.
Current build supports:
- PNG
- BMP
- Raw indexed BIN

The dialog also includes CoCo-targeted export options, but write-back into disk images is still incomplete in v1.0.8.
