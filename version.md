
# Kroma Paint v1.0.8

## Changes in this build
- Renamed the program to Kroma Paint
- Fixed project/version naming inside the folder and docs
- Added readme.md and manual.md
- Moved Load Project and Save Project next to each other in the File menu
- Changed New to New Project
- Changed About menu to Help
- Added version number to the Help/About dialog
- Added export modal for modern and CoCo-targeted export choices
- Default paint mode is now foreground color, not pattern
- Added pressed/active feedback for Foreground vs Pattern buttons
- Added built-in themed pattern sets
- Replaced old retro-computer palette list with uploaded palette presets
- Added slider value readouts in tool settings modals
- Flattened Filters menu so it is visible and usable
- Moved Brightness / Contrast into Filters
- Added Invert Colors, Low-pass, and High-pass filters
- Grid now shows at 200% zoom and up
- Snap to Grid now applies more consistently to drawing coordinates
- Flattened Display menu entries so Monitor and Window options work reliably
- Removed borders in the 4x4 Manage Patterns preview

## Remaining gaps
- Direct write-back into DSK images is still limited
- CoCo-native export packaging is still partial in this build
